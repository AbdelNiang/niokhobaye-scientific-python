# Niokhobaye Scientific Python

## Overview

This repository documents my progression in **scientific computing with Python**, from fundamental programming concepts to advanced numerical methods used in applied mathematics, machine learning, optimization, signal processing, and mathematical modeling.

The goal is not only to learn Python syntax, but also to develop the computational tools required for modern scientific research and engineering applications.
